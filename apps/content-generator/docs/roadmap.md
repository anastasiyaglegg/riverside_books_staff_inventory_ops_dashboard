# Riverside Books roadmap

This is a discovery-oriented roadmap. Dates are intentionally omitted until the first workflows and implementation constraints are validated.

## 1. Define

- Interview or observe the bookstore marketing workflow.
- Identify the first content formats and review criteria.
- List the highest-value customer support intents.
- Identify the approved source content for support answers.

## 2. Prototype

- Sketch the Product D request-to-draft flow.
- Prototype the Product C question-to-answer and handoff flow.
- Test both workflows with representative bookstore and customer scenarios.

## 3. Build the first slice

- Add the smallest runnable implementation for the validated Product D workflow.
- Add the smallest runnable implementation for the validated Product C workflow.
- Add tests for content grounding, review states, and fallback behavior.

## 4. Learn and expand

- Measure usefulness, editing effort, answer quality, and handoff rate.
- Improve source management and brand guidance.
- Expand into adjacent bookstore workflows only when the initial slice is reliable.
